# Guia do usuário (fatia vertical)

1. **Montagem**: ajuste componentes com − / +. Delta-v, massa, margem de energia e custo são recalculados
   pelo backend. Problemas de projeto aparecem como pontos vermelhos (erro) ou âmbar (aviso).
   O controle de propelente define a carga do tanque.
2. **Planejamento**: defina altitude inicial, altitude alvo e inclinação. O painel mostra o Δv necessário
   (Hohmann), o disponível e a margem. Se faltar Δv, é possível simular mesmo assim e ver a consequência.
3. **Operações**: a simulação roda no backend e a trajetória é reproduzida. Use a faixa inferior para
   pausar (espaço), navegar no tempo e escolher 1×–1000×. Clique num evento para ir até ele.
   "Detalhes técnicos" mostra modelo, referencial, integrador, deriva numérica e desempenho.
4. **Câmera**: Nave / Terra no topo. Arraste para orbitar e role para aproximar. A nave é desenhada
   ampliada (×1500); a física usa dimensões reais.
5. **Tela limpa**: tecla C ou botão no topo.
6. **Missões e checkpoints** (com banco configurado): ao simular, a missão é salva e aparece em
   Planejamento → Missões salvas. Em Operações, "Salvar checkpoint no instante atual" grava o estado físico
   naquele momento; "Retomar" continua a simulação a partir dele. Mudar a nave ou o plano cria uma nova missão.

Todos os componentes do catálogo atual são fictícios.
